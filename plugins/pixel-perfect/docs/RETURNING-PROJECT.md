# Refresh a returning project

1. Inspect `design/manifest.json` or `design/manifest.yaml`, actual source directories, selected platforms, and capture tooling. Use `pixel-perfect:status`. Inspect the manifest's shape and capture readiness; plugin version is not a project schema version. Status never migrates or installs anything.
2. Preserve the original manifest and current inventory/references before conversion. If conversion is needed, write a candidate beside the original, validate its platform/tool choices and component identities, and validate real capture setup. Promote only after validation succeeds. Keep the original as a recovery copy. Preserve Expo, NativeWind, React Native Reusables, and all platform configuration in projects using that stack.
3. Start the existing project through its normal commands and capture its actual current states. Repair missing capture setup through scaffold's capture step without resetting other completed phases. Existing v1 inventory and both supported object-platform and top-level-capture manifests need no version-driven reinitialization.
4. Save updated HTML/image exports or extract bundles with their sibling assets intact. Use `pixel-perfect:evolve --refresh ./exports --platform <name>`. The command stages a fresh render, preserves old references, compares the implementation, and presents one plan. For a precise named correction, use `refine` instead.
5. Resolve renamed source/frame mappings and omitted states explicitly. Confirm the complete scope once. Execute tokens/shared components first, then their consuming views. A partial export cannot authorize deletion.
6. Resume interrupted work with `pixel-perfect:evolve --resume <run-id>`. Keep completed work. Reconcile outside edits rather than resetting files. Run `pixel-perfect:verify --refresh <run-id>` to see regression, reference fidelity, affected behavior, and any incomplete evidence.
7. Treat older passes as historical. Complete only with fresh captures and checks for the full selected scope. Browser captures of React Native do not prove native-device behavior.

See `docs/REFRESH-CONTRACT.md` for exact helper inputs, persistence, and evidence rules. Pixel Perfect 9.3.0 ships the reference-refresh workflow and helpers; plugin checks passed; Ruthwell application acceptance is deferred to the user. Do not launch or refresh Ruthwell as part of plugin release validation.
